# Kesiswaan Supabase — Mockup

Mockup frontend statis untuk Sistem Informasi Kesiswaan SMKS Grafika.

## Menjalankan
Buka `index.html` langsung di browser atau gunakan VS Code + Live Server.

## Isi mockup
- Dashboard
- Presensi Pembiasaan Senin–Jumat
- Poin Pelanggaran
- Tindak Lanjut multi-record
- Rapor Karakter 8 Dimensi Profil Lulusan
- Rekap Pelanggaran
- Master Pembiasaan
- Kalender Sekolah
- Data Siswa
- Pengaturan Sekolah
- Preview role Superadmin, Kesiswaan, Guru/Wali Kelas, dan Siswa

## Catatan
Ini masih mockup UI + data demo. Tidak ada service_role key dan belum melakukan operasi Supabase.
Tahap berikutnya adalah mengganti data demo dengan Supabase JS client menggunakan publishable/anon key + RLS.
